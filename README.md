# 🎨 리더스아트 50분 출석부

자유 등원제 미술학원(리더스아트)에서 수시로 등원하는 아이들의 **50분 수업 시간**을 선생님 패드에서 한눈에 관리할 수 있는 출석 체크 웹 앱(PWA)입니다.

## 주요 기능
- **개인정보 유출 방지 (최소 정보 DB):** 전화번호, 주소, 생년월일 없이 `고유번호(S-001) + 표시이름 + 구분태그(유치부/초등저/초등고/중등부)`만 저장합니다.
- **원터치 등원 & 50분 개별 타이머:** 학생 터치 시 즉시 50분 카운트다운이 시작됩니다.
- **남은 시간순 자동 정렬:** 가장 먼저 하원해야 할 학생이 항상 맨 위에 표시됩니다.
- **신호등 안내 & 알림음:** 🔵 수업 중 → 🟡 10분 이하(마무리 준비) → 🔴 00:00 도달(하원 시간 & 초과 시간).
- **현장 보정 & 기록:** `-5분` / `+5분` 시간 조절, 간단 메모, 오늘 하원 기록 CSV 다운로드, 엑셀 일괄 등록.
- **실시간 패드 동기화 & PIN 잠금:** Firebase Firestore 연결 시 모든 선생님 패드가 실시간 동기화됩니다. (미연결 시 로컬 모드로 즉시 동작, 초기 PIN: `1234`)

## 다른 컴퓨터 / 선생님 패드에서 사용하는 방법

### 1. 무료 배포 (Vercel 추천)
1. [Vercel](https://vercel.com)에 GitHub 계정으로 로그인합니다.
2. **Add New Project** → `vegaking00/academy-50min-attendance` 선택 → **Deploy** 클릭.
3. 생성된 주소(예: `https://academy-50min-attendance.vercel.app`)로 어느 기기에서든 접속할 수 있습니다.

### 2. 여러 패드 실시간 동기화 설정 (선택)
1. [Firebase Console](https://console.firebase.google.com)에서 무료 프로젝트 생성 → **Firestore Database** 만들기.
2. Vercel 프로젝트의 **Settings → Environment Variables**에 `.env.example`에 있는 `VITE_FIREBASE_*` 값을 입력 후 재배포(Redeploy)합니다.
3. 학원 전용 PIN을 바꾸려면 `VITE_ACADEMY_PIN` 환경 변수에 원하는 숫자를 입력하세요.

### 3. 패드 바탕화면에 앱으로 등록 (PWA)
- **아이패드(Safari):** 접속 → 공유 버튼 → **홈 화면에 추가**
- **갤럭시 탭(Chrome):** 접속 → 우측 상단 `⋮` 메뉴 → **홈 화면에 추가**
